# Bin JSON 树形视图

日期：2026-10-04（Asia/Shanghai）。用户发现详情页树形 Tab 为灰色“即将推出”；本次补齐该入口，生产验收门槛继续单独跟踪。

## 行为

- 启用树形视图 Tab，展示当前编辑器 JSON 草稿；有 JSON 修改时提示未保存。切换 Tab 保留 JSON/元数据草稿与离开确认，查看或展开节点不写后端、不改变版本/ETag。
- 仅查看；编辑与保存继续使用现有编辑器。无效 JSON 显示修正提示及返回编辑器入口，不回退到已保存旧值。锁定 Bin 仍可查看。
- 根对象/数组默认展开，子容器默认折叠。显示字段/下标、类型、值或子项数量；null、false、0、空文本、空对象/数组均支持。
- 显示标准 JSON Pointer，字段中的 `/`、`~` 分别转义为 `~1`、`~0`；根指针为空。字段与字符串仅作为 React 文本渲染，不解释 HTML。
- 复制节点 JSON 使用原始解析值，包含完整长文本；剪贴板失败沿用可理解的错误提示。长文本只预览前 160 个 UTF-16 code units，避免截断代理对；预览不改变数据。
- 可见节点按 200 个分批显示；折叠全部恢复根节点视图及初始批量。遍历使用迭代器栈和扁平 DOM，避免深 JSON 递归挂载；只遍历已展开分支，后续批次不丢节点。
- 采用 tree/treeitem、显式层级/位置/集合大小、单一 Tab 焦点和选中状态。上下键移动、右键展开或进入、左键折叠或回父节点、Home/End 到当前可见首尾、Enter/Space 展开折叠。
- 手机/深色沿用现有颜色变量；超深视觉缩进封顶，真实 aria-level 和 Pointer 保留。树区域内滚动，不撑宽页面。

## 验证

- 3 项核心回归：基本值/长文本、标准 Pointer/特殊字段/顺序、宽树分批和深树迭代。
- 4 项真实浏览器回归：展开/键盘/复制/HTML 文本安全、草稿/保存/非法 JSON/离开确认、基本值与锁定、500 字段/完整长文本复制/390px 深色。
- 生产构建 CSP 测试增加树形当前值检查；继续要求零 violation / pageerror。
- 类型、production build、完整自动化与浏览器检查通过后推送 main，并记录精确功能 SHA 的 CI / Workers Builds。真实生产站点验收与 stable 发布仍需要实际 URL/认证/Cron 证据。
