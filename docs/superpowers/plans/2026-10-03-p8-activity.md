# P8 活动记录实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供不含敏感信息、持久保存于 R2 的重要操作记录及中文管理界面。

**Architecture:** 每条记录使用独立不可变 R2 对象，成功操作显式调用记录 helper。可信身份来自 Session/API Key 认证；列表只允许管理 Session。复用现有 Cron 清理至最近 2000 条，活动写入失败保持已提交业务的原结果。

**Tech Stack:** 现有 TypeScript、Hono、Zod、R2、React Query、Node test、Miniflare、Playwright；无新增依赖。

**Spec:** 已由用户确认的 `docs/superpowers/specs/2026-10-03-p8-activity-design.md`，以及 `docs/DEVELOPMENT.md` P8。远端基线 `f75a9dfd37a6bc3e900a679c08167c4f5e5a658f`；开发分支 `codex/p8-activity`。

## Global Constraints

- R2 是唯一权威数据源；KV 清空不丢失活动记录。不新增数据库、依赖或外部日志服务。
- 禁止记录密码、Cookie、Authorization、完整 Token、Token 摘要、OAuth code/state、请求/响应正文、敏感 JSON、资源名称/描述、字段路径、自填用户名。
- id/requestId 由服务端产生 UUID；action、resourceType、summary 使用封闭映射，不能由请求传入自由文本。
- 管理 Session 才能读取；显式 Authorization 返回 401 session_required，即使同时有 Cookie。不新增 Scope。
- 记录最多三次条件创建尝试；活动失败不把已成功业务改报 500。不承诺跨对象原子提交或恰好一次投递。
- 默认保留最近 2000 条，每 15 分钟 Cron 最终收敛；短时或故障期间可能超过上限。清理只删除合法 activity 对象键。
- 中文 UI、移动布局、深色主题、既有草稿导航保护；不加入 P9 文档、导出、全文搜索或日志编辑接口。
- 使用现有云检出目录，不另建 worktree；原生执行，最终一次 fresh review（可用性与结果如实记录）。
- 合并 main/推送沿用此前授权；CI/Workers Builds 与生产功能/真实 Cron 手动验收分别记录。

## Review Focus

1. API Key 创建的响应含 token，但活动捕获不能读取/复制该响应；已通过认证的 key 身份不能被客户端 Request-ID 或用户名替换。（Task 2/3 隐私正向+反向测试）
2. 成功业务之后活动存储失败或 Worker 中断，不能改报可诱发重试的业务失败，也不能宣称操作记录永不遗漏。（Task 2 故障注入）
3. 回收站批量部分成功和 Cron 幂等续作不能给失败项目、已 purged 的 tombstone 生成新的成功迁移事件。（Task 3）
4. 同毫秒写入、并发新增/清理及删除了游标锚点时，分页不能重复已有项或越过 activity 前缀，清理不能删除最近的记录。（Task 1/2/3）
5. 切换过滤、刷新或离开页面后，旧分页请求不能拼入新结果；401 不应静默清空已加载的内容。（Task 4）

## 文件与接口边界

- `src/shared/activity.ts`：纯类型、action/中文 summary/resourceType 封闭映射，可供 Worker 与客户端共用。
- `src/worker/storage/activity.ts`：严格白名单、不可变写入、R2 列表分页/筛选、保留清理；不依赖 HTTP Context。
- `src/worker/activity.ts`：HTTP 服务端 requestId、可信 identity、fail-open 记录 helper、固定故障信号。
- `src/worker/routes/activity.ts`：Session-only 列表及参数校验，无记录写入入口。
- 现有 `middleware/auth.ts` 和资源 routes：设置可信 identity / 显式记录成功动作，不解析审计用的请求/响应正文。
- `src/worker/storage/trash.ts`：后台实际状态迁移通知，避免 purged 幂等扫描重复记账。
- `src/react-app/features/activity/api.ts`、`ActivityPage.tsx`：列表客户端与独立页面；App 只接入路由/导航。
- 现有 Worker 测试扩充真实 R2 验证；新增 `tests/activity.test.mjs` 用编译后的 Worker entry + 最小故障 R2 adapter 检查 failure/OAuth，无新 test dependency；新增浏览器验收。
