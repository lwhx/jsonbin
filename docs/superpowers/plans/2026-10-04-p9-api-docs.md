> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

`types.ts` 定义：`ExampleLanguage = 'curl' | 'javascript' | 'python'`；`DocAuth = 'none' | 'session' | 'resource'`；`EtagPolicy = 'none' | 'optional' | 'required' | 'conditional'`；`DocScope` 为现有九种完整 Scope。

`DocSection = {id: string, title: string, introduction: string[]}`；`DocError = {status: number, code: string, meaning: string, recovery: string}`。DOC_SECTIONS/OPERATIONS/ERRORS/SCOPES 分别为对应类型的只读数组。

`DocOperation` 字段：`id, sectionId, title, method, path, auth, scopes, etag, publicRead, description, requestFields, responseShape, successStatus, body?`。method 为 GET/POST/PUT/PATCH/DELETE；path 是 `/api/v1/...` 模板，scopes 表示全部必需权限，publicRead 仅用于当前 Bin/路径 GET。body 是固定 JSON 演示值。

`ExampleContext` 字段：`origin: string, binId?: string, etag?: string, collectionId?: string, schemaId?: string, keyId?: string, version?: number, pathSegments?: string[], anonymous?: boolean`。只传白名单字段，不传 BinRecord。默认演示资源 ID 使用明确标注为需替换的有效 UUID，版本 1，路径 `['settings','theme']`；默认 Token 为 `<API_TOKEN>`，ETag 为带引号的 `<ETAG>`。测试凭据只在 test harness 内替换占位符，不扩展产品接口。

`ExampleRequest = {method: DocOperation['method'], url: string, headers: Record<string,string>, body?: unknown, credentials?: 'include'}`。
